## Routing file import (`RoutingPresetSelect::buttonClicked`, ev_f761b9e0…)
- The original offers 6 recall scopes. They are local flags at `_local→routing+0x70…0x98`:

  | Scope | Lines it applies |
  |---|---|
  | channel inputs | `insrc` |
  | USB returns | `rtnsrc`, `rtnsw` |
  | USB send | `routing/usb` |
  | Ultranet | `routing/p16` |
  | aux | `routing/aux` |
  | main | `routing/main` |
- Lines outside the active scopes are dropped.

## USB recorder (ev_c324243d…, ev_8c17582f…)
- **Open a folder:** `/-stat/usb/path` = path + "/" + name, then re-read `/-stat/usb` and its entries.
- **Up a folder:** truncate the path at the last "/".
- **Play a file:** `/-stat/tape/file` = path/name, then `/-stat/tape/state` = 2 (PLAY).
- **Prev/next track:** skip folders (type 1).
- **Transport** (states: 0 STOP, 1 PPAUSE, 2 PLAY, 3 RPAUSE, 4 REC, 5 FF, 6 REW):

  | Button | Result |
  |---|---|
  | Stop | 0 |
  | Play | 2; stays put while in 3 or 4 |
  | Pause | 1↔2 and 3↔4 |
  | REW / FF | 6 / 5, only from 1 or 2 |
  | Record | 4 from 0 or 3; 3 from 4 (mini buttons) |

## Proven or resolved
- **MIDI bit order** (`MainContentComponent::handleMessage`, ev_ec1ae2cc…): bit0 DIN Rx, 1 DIN Tx, 2 DIN X-OSC, 3 USB Rx, 4 USB Tx, 5 USB/OSC, 6 USB-DIN Pass Thru.
- **Scene files have no header.** `Cfileio::saveFile` writes the text verbatim and `loadSceneFile` parses every line (ev_ebe247ad…).
- **Solo switches 33–54** are never read by the desktop app; the only stat member past 32 is `/-stat/rta`.

## Client behaviours
- **Soft mute groups** (`CmessageQueue::run` case 0x13). While `/-prefs/hardmute` is OFF, toggling `/config/mute/N`:
  - ON: sets `mix/on` = 0 on every strip of the 31 (ch, aux, FX returns, buses, FX sends) whose `grp/mute` has bit N;
  - OFF: unmutes only strips that no other active group holds.

  While hardmute is ON, it is display only.
- **`checkHardMute` display:** a strip shows as muted when hardmute is ON and an active group contains it, or when dcamute is ON and an assigned DCA is off.
- **`invertmutes` (NORM/INV):** changes the mute button's label and colour.
- **`fdrfine`:** `mFader::resized` doubles the fader travel length.
- **`autosel` (`mFader::sliderValueChanged`):** moving a fader selects that channel (`chan/selidx`).
- **`sendslink`:** the tap selection writes the same send number on all 16 channels, the aux return and four FX returns when enabled. Send level and pan remain independent.

## Additional checks

- `RecorderControl::RecorderControl` at 0x100064ad0 binds the two source and tap selectors. Reading the constructed tree in the stopped scratch process resolved the four pointers to USB routes 01/02, each with `src` and `pos`.
- `Cpreset::savePreset` (0x1000342fc), `Cnode::getAllParams` (0x10001e410), `Cpasteselect::buttonClicked` (0x1000359e8) and `Cfileio::saveNode2File` (0x100032354) establish the channel and FX file roots, node selection and cross-size EQ mapping. The test fixtures include a gate preset and a Hall effect preset from the desktop serializer.
- `ChannelGate::setParams` (0x1000c96ac) and `ChannelCompressor::setParams` (0x1000a6120) identify the threshold faders that receive block 0 registers 6 and 7. Gain reduction is at 2 and 3. The gate and compressor registers in block 6 provide the corresponding all-strip overview. [Behringer remote control protocol, pp. 3–4](https://cdn-media.empowertribe.com/fa303061bf2f48a7b07eba14e1c82271/X%20AIR%20Remote%20Control%20Protocol.pdf#page=3)
- `state_initializeConsole` (0x100017bc8) sets the subgroup defaults on the smaller models and the default input for XR12 strips 13–16. The manufacturer’s block diagram confirms the split-input signal path. [X AIR manual, §3.2.3](https://images.thomann.de/pics/atg/atgdata/document/manual/333932_x_air_manual_en.pdf#page=13)
